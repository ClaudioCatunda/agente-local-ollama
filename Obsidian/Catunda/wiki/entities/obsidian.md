# Obsidian

Editor de markdown local baseado em arquivos. Neste vault, atua como a **"IDE"** onde Catunda navega o wiki em tempo real enquanto eu o escrevo.

## Recursos úteis ao padrão
- **Web Clipper** — converte artigos web em markdown (captura de fontes).
- **Graph view** — melhor forma de ver a forma do wiki (hubs, órfãos, conexões).
- **Marp** — slides a partir de markdown.
- **Dataview** — queries sobre o frontmatter YAML das páginas.
- Download de imagens local (Attachment folder + hotkey) → `raw/assets/`.
